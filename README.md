# R & RStudio Workshops

Slides and code for a two-part introduction to R for researchers.

- `pt1-slides.qmd`: Pt. 1 slide source (Quarto revealjs)
- `pt1-slides.html`: rendered slides, self-contained
- `pt1-code.R`: all Pt. 1 code in one script for students
- `custom.scss`: slide theme
- `index.html`: landing page served by GitHub Pages

## Rebuilding the slides

Open `pt1-slides.qmd` in RStudio and click **Render**, or run:

```
quarto render pt1-slides.qmd
```
